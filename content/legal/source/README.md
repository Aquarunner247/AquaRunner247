# Original source documents

The `.docx` files the operator drafted externally, kept verbatim as they were handed over on
2026-10-21 so the edited Markdown in the parent directory can always be diffed against its
starting point. Nothing in the app reads this directory -- the routed pages read the `.md`
files in `content/legal/` directly.

If you re-edit a document in Word, replace the `.docx` here AND port the change into the
`.md`; the `.md` is what the site serves.
